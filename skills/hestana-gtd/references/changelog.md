# Changelog

## 0.1.0
First release as a standalone skill (ADR-696), rewritten from the gtd 0.1.0 package of hestana-core. Five lists mapped to the task model: Inbox and Someday/maybe as two codes of backlog, Next actions as open, Waiting for as waiting, Done; projects as tasks with subtasks; context reduced to availability; agents capture and propose, the person clarifies, organizes and reviews. Adds the Hestana mechanics for planning and execution and reads the Space's methodology from `spaces_get`.
