# Handoff (a comment on the task, label `handoff`)

Written on every exit: done, paused, waiting, expired, released, canceled. It must stand alone; link evidence, do not paste it.

- **State:** what is done and what remains; last observed status code and assignment.
- **Agreement:** task version worked against; decisions relied on; methodology and version exactly as `spaces_get` returned them (`<id> <version>`, or none).
- **Evidence:** commits, documents (with version), URLs; each check and its outcome, failures included.
- **Waiting for / questions:** who, since when, what depends on it; open mentions (recipient, what waits on the answer); `blockedBy`. "None" if none.
- **Coordination:** assignment closed, released, handed to a named principal, or kept until an explicit instant.
- **Next action:** one concrete physical step, and what to re-read first.
