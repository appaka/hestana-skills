# Weekly review

- [ ] Empty the Inbox: clarify every item.
- [ ] Next actions: finish what is done, drop what no longer matters, release what is stuck.
- [ ] Projects: each one has a next action in Next actions; if not, define it or cancel the project.
- [ ] Waiting for: chase what has been quiet; close what arrived.
- [ ] Someday/maybe: activate what is ready, cancel what is no longer wanted.
- [ ] Anything new on your mind: capture it.

The person runs the review. An agent may prepare a digest of what is stale and moves nothing.
