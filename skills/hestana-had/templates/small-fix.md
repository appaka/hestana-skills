# Small fix template

Use one task for a bounded correction whose expected behavior is established. Add detail or switch to discovery if the expected behavior or authority is uncertain.

Replace braces with actual context and remove unused prompts. This is a writing aid, not a server schema or an authorization.

```markdown
# {Bounded correction}

Problem: {reproduction and observable current result, with relevant evidence}

Expected: {established behavior and its source; success case and relevant failure/permission case}

Scope: {what changes and what is excluded}

Inputs and execution: {minimum readable context, any real prerequisite, current authorization and applicable code/project rules}

Check: {how to verify the expected behavior and relevant regression; required review per existing policy}

Result and next step: {fill only after work: artifact/revision, actual check/review outcomes, acceptance/release state, unresolved blocker or next action}
```
